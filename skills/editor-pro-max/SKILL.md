# Editor Pro Max

Programmatic video editing inside this repo. No timeline GUI: you describe the edit, Claude writes a React composition, Remotion renders it to MP4.

Vendored from <https://github.com/Hainrixz/editor-pro-max> (by [@soyenriquerocha](https://instagram.com/soyenriquerocha), MIT) into **`tools/editor-pro-max/`**. Pinned revision is in `tools/editor-pro-max/.vendor-rev`.

## Where this sits in the pipeline

| Need | Skill |
|---|---|
| Generate AI footage / UGC / b-roll | `arcads-external-api` |
| Generate a static image ad | `chatgpt-image-ad` / `nano-banana-image-ad` |
| **Cut, caption, assemble, brand, render a video** | **this skill** |
| Publish the finished file as a Meta ad | `meta-ad-builder` |

Typical chain: Arcads generates the raw clips → Editor Pro Max stitches them, burns captions and adds the CTA/watermark → `meta-ad-builder` uploads the MP4 as a PAUSED ad.

> The `shared/skills/caption-video/prompting/guide.md` route (HyperFrames + Whisper + ffmpeg chroma-key) is the *older, standalone* captioning path. Prefer Editor Pro Max when the video also needs cuts, overlays or a layout; use `caption-video` when captions are the only thing needed and you don't want a Node project in the loop.

## When to use

Trigger on:
- "edit my video", "cut the dead air", "remove the silences"
- "add captions / subtitles to this video", "TikTok-style captions"
- "make me a TikTok / Reel / Short about X"
- "extract a 30s clip for Instagram", "make a square version"
- "add a watermark / lower third / progress bar / CTA"
- "render this for YouTube / TikTok / Twitter"
- any mention of Remotion, Remotion Studio, compositions, `npx remotion render`

## Prerequisites

Everything runs locally, **no API key required**.

- Node.js 18+ and npm
- `ffmpeg` on PATH (`ffmpeg -version`) — required by the pipeline scripts
- First run only: `cd tools/editor-pro-max && npm install` (~1–2 min; `node_modules/` is gitignored)
- Whisper model is downloaded on demand by `scripts/transcribe.ts` (first transcription is slow)

Verify the project compiles before editing: `cd tools/editor-pro-max && npx tsc --noEmit`.

## Path A — create a video from scratch

1. Pick the closest template, or compose from the 25 components.
2. Write/modify the composition under `tools/editor-pro-max/src/compositions/` and register it in `src/Root.tsx`.
3. Preview: `cd tools/editor-pro-max && npm run dev` → Remotion Studio on <http://localhost:3000>.
4. Render: `npx remotion render <CompositionId> out/video.mp4`.

Registered compositions: `Showcase`, `TikTok`, `InstagramReel`, `YouTubeShort`, `Presentation`, `Testimonial`, `Announcement`, `BeforeAfter`, `TalkingHeadEdit`, `PodcastClip`.

## Path B — edit existing footage

1. Put the source file in `tools/editor-pro-max/public/assets/` (gitignored — media stays local).
2. Run the pipeline from `tools/editor-pro-max/`:
   ```bash
   npx tsx scripts/analyze-video.ts      # dimensions, fps, duration
   npx tsx scripts/extract-audio.ts      # wav for Whisper
   npx tsx scripts/transcribe.ts         # word-level captions (Whisper)
   npx tsx scripts/detect-silence.ts     # dead-air ranges to cut
   npx tsx scripts/remove-bg.ts          # optional, background removal
   ```
3. Build the composition — `TalkingHeadEdit` (auto-captions + `JumpCut`) and `PodcastClip` (vertical clip + captions) are the ready-made starting points.
4. Preview in Studio, then render.

## Component map

- **Text** — `AnimatedTitle` (8 styles), `LowerThird`, `TypewriterText`, `WordByWordCaption`, `CaptionOverlay` (5 TikTok-style presets)
- **Backgrounds** — `GradientBackground`, `ParticleField`, `GridPattern`, `ColorWash`
- **Overlays** — `ProgressBar`, `Watermark`, `CallToAction`, `CountdownTimer`
- **Media** — `FitVideo`, `FitImage` (Ken Burns), `Slideshow`, `VideoClip` (trim), `JumpCut` (silence removal), `ImageOverlay`, `AudioTrack` (ducking)
- **Layout** — `SplitScreen`, `PictureInPicture`, `SafeArea`
- **Transitions** — 12 presets in `src/components/transitions/TransitionPresets.ts`
- **Presets** — 7 palettes, 8 gradients, 12 easings, 5 fonts, 9 platform dimensions under `src/presets/`

## Rendering

```bash
cd tools/editor-pro-max
npx remotion render TikTok out/tiktok.mp4                    # 1080x1920
npx remotion render Presentation out/deck.mp4                # 1920x1080
./scripts/render.sh <CompositionId> out/name.mp4             # wrapper
./scripts/batch-render.sh                                    # all compositions
```

Output lands in `tools/editor-pro-max/out/` (gitignored). Copy or move the final MP4 out of there before handing it to `meta-ad-builder`.

## Pitfalls

- **Never edit files under `tools/editor-pro-max/` expecting them to sync to `.claude/skills/`.** Only `SKILL.md` files directly under `skills/` and `shared/skills/` are synced by `shared/scripts/sync-skill.sh`. This file is the canonical source for the skill — edit it here, then run `./scripts/sync-skill.sh`.
- **Media and renders are gitignored** (`public/assets/`, `out/`, `media/`, `node_modules/`). Nothing heavy gets committed; conversely, don't assume a teammate has your source footage.
- **`npx tsc --noEmit` before rendering.** Remotion fails late and noisily on type errors.
- **Durations are in frames, not seconds** (`durationInFrames = seconds * fps`, default 30fps). Off-by-30 is the classic bug.
- **Upgrading the vendored copy**: re-clone upstream, diff against `tools/editor-pro-max/`, and bump `.vendor-rev`. Local changes to the vendored tree are yours to re-apply.
